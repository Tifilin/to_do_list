# Консольный менеджер задач (To-Do List)

Консольное приложение на Python для создания и управления персональным списком задач.

Программа позволяет добавлять, просматривать, фильтровать, сортировать, искать, выполнять и удалять задачи. Данные сохраняются в JSON-файл `tasks.json` и автоматически загружаются при запуске программы.

Дополнительно реализована возможность экспорта списка задач в текстовый файл и CSV-файл.

Проект выполнен в рамках учебного задания:

**«Кейс 7: Консольный менеджер задач (To-Do list)»**

---

## 1. Цель проекта

Цель проекта — разработать консольное приложение на Python для ведения персонального списка задач с сохранением данных между запусками программы.

Основные задачи проекта:

* реализовать добавление новых задач;
* реализовать просмотр списка задач;
* реализовать фильтрацию задач;
* реализовать сортировку задач;
* реализовать отметку задачи как выполненной;
* реализовать удаление задачи с подтверждением;
* реализовать сохранение данных в JSON-файл;
* реализовать автоматическую загрузку данных при запуске;
* добавить проверку пользовательского ввода;
* реализовать обработку ошибок при работе с JSON-файлом;
* использовать ИИ-инструмент для разработки отдельных функций;
* реализовать дополнительные функции поиска и экспорта данных.

---

## 2. Функциональные возможности

Программа предоставляет следующие возможности:

1. Добавление новой задачи.
2. Просмотр всех задач.
3. Фильтрация задач по статусу.
4. Фильтрация задач по приоритету.
5. Отметка задачи как выполненной.
6. Удаление задачи с подтверждением.
7. Сортировка задач:

   * по сроку выполнения;
   * по приоритету;
   * по статусу.
8. Экспорт задач в TXT.
9. Экспорт задач в CSV.
10. Поиск задач по ключевому слову в названии.
11. Сохранение задач в `tasks.json`.
12. Автоматическая загрузка задач при запуске.
13. Резервное сохранение в `tasks_backup.json`, если основная запись не удалась.
14. Валидация названия задачи.
15. Валидация даты выполнения.
16. Валидация приоритета.
17. Обработка ошибок чтения и записи JSON-файла.

# 7. Добавление задачи

Для создания новой задачи необходимо выбрать пункт:

```text
1 Добавить новую задачу
```

Программа последовательно запрашивает:

* название;
* описание;
* дату выполнения;
* приоритет.

Пример:

```text
Добавление новой задачи
------------------------------
Название задачи: Изучить Python
Описание (Enter для пропуска): Повторить работу с JSON
Планируемая дата выполнения задачи в формате ДД.ММ.ГГГГ: 25.08.2026

Выберите приоритет:
  1 - Высокий
  2 - Средний
  3 - Низкий

Приоритет (1-3): 1
```

После успешного добавления программа сообщает:

```text
Задача 1 добавлена (Изучить Python)
Данные успешно сохранены.
```

---

# 8. Структура задачи

Каждая задача хранится в виде объекта со следующими полями:

| Поле             | Тип            | Описание                        |
| ---------------- | -------------- | ------------------------------- |
| `id`             | `int`          | Уникальный идентификатор задачи |
| `name`           | `str`          | Название задачи                 |
| `description`    | `str`          | Описание задачи                 |
| `target_date`    | `str` / `null` | Планируемая дата выполнения     |
| `priority`       | `str`          | Приоритет задачи                |
| `completed`      | `bool`         | Статус выполнения               |
| `completed_date` | `str` / `null` | Дата и время выполнения         |
| `created_at`     | `str`          | Дата и время создания           |

Пример:

```json
[
    {
        "id": 1,
        "name": "Изучить Python",
        "description": "Повторить функции и работу с JSON",
        "target_date": "25.08.2026",
        "priority": "высокий",
        "completed": false,
        "completed_date": null,
        "created_at": "2026-08-17 10:30:00"
    }
]
```

---

# 9. Просмотр задач

Для просмотра всех задач необходимо выбрать:

```text
2 Показать список задач
```

Пример результата:

```text
#1 | Изучить Python | Приоритет: высокий | Дата: 25.08.2026
Повторить функции и работу с JSON
Создана: 2026-08-17 10:30:00
----------------------------------------
```

После выполнения задачи отображается её статус.

Например:

```text
#1 | Изучить Python | Приоритет: высокий | Срок: 25.08.2026 | Статус: Выполнена
Описание: Повторить функции и работу с JSON
```

Для активной задачи:

```text
#1 | Изучить Python | Приоритет: высокий | Срок: 25.08.2026 | Статус: Активна
```

---

# 10. Фильтрация по статусу

Программа позволяет разделить задачи на активные и выполненные.

Для этого используется пункт:

```text
3 Отфильтровать задачи по статусу выполнения
```

Доступны два варианта:

```text
1 - Активные задачи
2 - Выполненные задачи
```

Активной считается задача, у которой:

```python
"completed": false
```

Выполненной считается задача, у которой:

```python
"completed": true
```

Если подходящих задач нет, программа выводит сообщение:

```text
Нет задач с такими параметрами
```

---

# 11. Фильтрация по приоритету

Для фильтрации по приоритету используется пункт:

```text
4 Отфильтровать задачи по приоритету
```

Доступны следующие значения:

```text
1 - Высокий
2 - Средний
3 - Низкий
```

Например, при выборе высокого приоритета будут показаны только задачи:

```text
"priority": "высокий"
```

---

# 12. Отметка задачи как выполненной

Для изменения статуса задачи используется пункт:

```text
5 Отметить задачу выполненной
```

Перед выбором задачи программа показывает активные задачи.

Пользователь вводит ID задачи:

```text
Введите ID задачи, чтобы отметить её выполненной: 2
```

После этого поле:

```json
"completed": false
```

изменяется на:

```json
"completed": true
```

Также сохраняется дата и время выполнения:

```json
"completed_date": "2026-08-17 12:15:30"
```

После успешного выполнения появляется сообщение:

```text
Задача #2 «Изучить Python» выполнена.
```

Если задача уже была выполнена:

```text
Задача #2 уже выполнена ранее.
```

---

# 13. Удаление задачи

Для удаления используется пункт:

```text
6 Удалить задачу из списка
```

Сначала пользователь вводит ID задачи:

```text
Введите ID задачи для удаления: 3
```

Программа показывает информацию о выбранной задаче:

```text
Вы собираетесь удалить задачу:
  #3 | Подготовить отчёт
```

Затем запрашивается подтверждение:

```text
Удалить? (y/n):
```

Если пользователь вводит:

```text
y
```

производится дополнительное подтверждение.

```text
Дополнительная проверка ИИ. Вы действительно хотите удалить задачу? (y/n):
```

После подтверждения задача удаляется из списка и изменения сохраняются в `tasks.json`.

Если пользователь выбирает `n`, удаление отменяется.

---

# 14. Сортировка задач

Для сортировки используется пункт:

```text
7 Сортировать список задач
```

Доступны три варианта:

```text
1 - По сроку выполнения
2 - По приоритету
3 - По статусу
```

## 14.1. Сортировка по сроку

Задачи сортируются по дате выполнения от ближайшей к более поздней.

Например:

```text
20.08.2026
22.08.2026
25.08.2026
```

Задачи без указанного срока помещаются в конец списка.

## 14.2. Сортировка по приоритету

Используется следующий порядок:

```text
Высокий
Средний
Низкий
```

В программе это реализовано с помощью соответствия:

```python
priority_order = {
    "высокий": 1,
    "средний": 2,
    "низкий": 3
}
```

## 14.3. Сортировка по статусу

Сначала выводятся активные задачи:

```text
Статус: Активна
```

затем выполненные:

```text
Статус: Выполнена
```

---

# 15. Экспорт задач

В программе дополнительно реализована возможность экспорта задач.

Для этого используется пункт:

```text
8 Экспортировать список задач в текстовый файл или csv
```

Доступны два формата:

```text
1 - Экспорт в текстовый файл (.txt)
2 - Экспорт в CSV-файл (.csv)
```

---

## 15.1. Экспорт в TXT

При выборе первого варианта создаётся файл:

```text
tasks.txt
```

Пример содержимого:

```text
ID: 1
Название: Изучить Python
Описание: Повторить работу с JSON
Срок выполнения: 25.08.2026
Приоритет: высокий
Статус: Активна
Дата выполнения: Не выполнена
--------------------------------------------------
```

---

## 15.2. Экспорт в CSV

При выборе второго варианта создаётся файл:

```text
tasks.csv
```

CSV-файл содержит следующие столбцы:

```text
id
name
description
target_date
priority
completed
completed_date
```

Пример:

```text
id,name,description,target_date,priority,completed,completed_date
1,Изучить Python,Повторить работу с JSON,25.08.2026,высокий,Нет,
```

Для записи CSV используется стандартный модуль Python `csv`.

---

# 16. Поиск задач

В программе реализован поиск задач по ключевому слову в названии.

Для запуска поиска используется пункт:

```text
9 Поиск задач по ключевому слову в названии
```

Пользователь вводит ключевое слово:

```text
Введите ключевое слово для поиска в названии: Python
```

Поиск не зависит от регистра букв.

Например, запрос:

```text
python
```

найдёт задачу:

```text
Изучить Python
```

Если задачи не найдены:

```text
Задачи с ключевым словом «Python» не найдены.
```

---

# 17. Валидация пользовательского ввода

Программа содержит несколько механизмов проверки данных.

## 17.1. Проверка названия

Название задачи не может быть пустым.

Если пользователь нажмёт Enter, не введя название:

```text
Название задачи не может быть пустым!
```

---

## 17.2. Проверка даты

Дата проверяется с помощью функции:

```python
validate_task_date()
```

Дата должна соответствовать формату:

```text
ДД.ММ.ГГГГ
```

Например:

```text
25.08.2026
```

Функция также проверяет существование даты в календаре.

Некорректный вариант:

```text
32.08.2026
```

Результат:

```text
Ошибка: дата должна быть введена в формате ДД.ММ.ГГГГ!
```

Также дата не может быть прошедшей.

Например:

```text
Введите дату: 01.01.2020
```

Результат:

```text
Ошибка: дата выполнения не может быть прошедшей!
```

Для проверки используется модуль:

```python
datetime
```

---

## 17.3. Проверка приоритета

Приоритет выбирается только из доступного списка:

```text
1 - Высокий
2 - Средний
3 - Низкий
```

Если пользователь вводит другое значение:

```text
Ошибка: выберите приоритет 1, 2 или 3!
```

---

## 17.4. Проверка ID задачи

При выполнении или удалении задачи ID должен быть числом.

Например, если пользователь вводит:

```text
abc
```

программа сообщает:

```text
ID должен быть числом!
```

---

# 18. Сохранение данных

Основным файлом хранения является:

```text
tasks.json
```

При каждом изменении списка задач вызывается функция:

```python
save_tasks()
```

Она передаёт данные в функцию:

```python
handle_json_file("write", tasks_list)
```

После успешной записи программа сообщает:

```text
Данные успешно сохранены.
```

---

# 19. Загрузка данных

При запуске программы вызывается функция:

```python
load_tasks()
```

Она проверяет наличие файла `tasks.json`.

Если файл существует, данные загружаются с помощью:

```python
json.load()
```

Если файл отсутствует, программа начинает работу с пустым списком задач.

---

# 20. Обработка ошибок JSON

В проекте реализована отдельная функция:

```python
handle_json_file()
```

Она отвечает за обработку ошибок чтения и записи JSON-файла.

Функция поддерживает два режима:

```text
read
write
```

---

## 20.1. Отсутствие файла

Если `tasks.json` отсутствует, программа сообщает:

```text
Файл tasks.json не найден. Создаётся пустой список задач.
```

После этого программа продолжает работу.

---

## 20.2. Повреждённый JSON

Если файл содержит некорректный JSON:

```text
Ошибка: файл tasks.json повреждён или содержит некорректный JSON.
```

Программа не завершается аварийно.

# 21. Резервное сохранение

В функции `save_tasks()` предусмотрен дополнительный механизм сохранения.

Если основная запись в:

```text
tasks.json
```

не удалась, программа пытается сохранить данные в:

```text
tasks_backup.json
```

Пример сообщения:

```text
Основное сохранение не удалось - скрипт, разработанный ИИ выявил ошибку.
Данные сохранены в резервный файл tasks_backup.json.
```

Если резервное сохранение также невозможно, программа выводит сообщение об ошибке.
