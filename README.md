# to_do_list
Учебный проект

ЗАДАНИЕ
Кейс 7: Консольный менеджер задач (To-Do list)

	Цель: Разработать программу на Python для ведения персонального списка задач (To-Do list) с возможностью добавления, просмотра, отметки выполнения и удаления задач. Использовать ИИ-инструмент для генерации кода валидации ввода и обработки ошибок при работе с файлами.

	Задачи:
1.	Реализовать следующие функции управления задачами:
		- добавление новой задачи (название, описание, срок выполнения, приоритет)
		- просмотр списка задач с возможностью фильтрации (все, только активные, только выполненные)
		- отметка задачи как выполненной
		- удаление задачи (с подтверждением)
2.	Обеспечить сохранение задач в JSON-файл (tasks.json) при каждом изменении списка и автоматическую загрузку при запуске программы. Формат хранения должен позволять восстанавливать все поля задачи (включая статус выполнения).
3. Добавить валидацию пользовательского ввода:
	а) название задачи не может быть пустым
	б) дата срока выполнения должна быть в формате ДД.ММ.ГГГГ и не может быть прошедшей
	в) приоритет должен выбираться из списка (высокий, средний, низкий) – по заданию.
4. Реализовать сортировку задач при просмотре:
	- по сроку выполнения
	- по приоритету (высокий – средний – низкий)
	- по статусу (активные перед выполненными)
5. Использовать ИИ-инструмент для генерации кода:
- проверки корректности введённой даты и сравнения с текущей.
- обработки ошибок при чтении/записи JSON-файла (отсутствие файла, повреждённые данные, права доступа)
- реализации подтверждения при удалении задачи
6. Создать консольное меню с понятными пунктами (добавить, показать, выполнить, удалить, выход). При просмотре задач отображать их порядковые номера, статус, срок, приоритет и название.
7. Добавить (опционально):
	- подсветку просроченных задач красным цветом с помощью библиотеки colorama
 	- возможность экспорта списка задач в текстовый файл и CSV
	- поиск задач по ключевому слову в названии
